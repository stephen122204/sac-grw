# Evidence status after manuscript review

`nonlinear_mse_corrected.json` is **unverified and excluded from the manuscript**.
Its ratios cannot be recovered from the archive it names, and no generating
driver was located. It is retained unchanged as historical material, not a
second valid answer. Use the float64 partner replay in
`manuscript/evidence/replayed_fields.npz` and the explicit empirical-MSE
calculation in `manuscript/analysis/build_numbers.py` instead.

`calibration.json` uses the earlier common-shape design. The current article
uses the separately resampled two-shape design in the round-25 calibration
archive, with its restricted interpretation. Neither calibration proves
coverage for integrated-field or MSE intervals.

Costs and the other archived data are cited only where named by the current
manuscript's evidence map. The 0.598/1.008 values in the unverified nonlinear
file must not be used to support a current claim.
